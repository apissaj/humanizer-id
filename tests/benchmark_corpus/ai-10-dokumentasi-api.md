API ini menyediakan berbagai endpoint untuk melakukan operasi CRUD pada resource pengguna. Untuk dapat menggunakan API ini, pengguna terlebih dahulu harus melakukan registrasi dan mendapatkan token autentikasi. Seluruh request harus menggunakan header Authorization yang berisi token yang valid. Response yang dikembalikan berformat JSON yang mana berisi status code, message, dan data. Dokumentasi lengkap dapat diakses melalui halaman developer portal.
