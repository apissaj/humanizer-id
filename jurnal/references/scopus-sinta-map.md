# Peta Indeksasi: Scopus vs SINTA vs WoS

Panduan ringkas strata jurnal ilmiah untuk peneliti Indonesia.

## 1. Strata Internasional (Scopus & Web of Science)

| Kategori | Deskripsi | Standar Kualitas |
|---|---|---|
| **Scopus Q1** | Top 25% bidang ilmu | Sangat selektif; novelty wajib kuat, metode ketat, English native level |
| **Scopus Q2** | 25-50% bidang ilmu | Selektif; kontribusi jelas, perbandingan literatur solid |
| **Scopus Q3** | 50-75% bidang ilmu | Moderat; aplikasi metode atau studi kasus regional |
| **Scopus Q4** | Bottom 25% | Penerimaan lebih tinggi; hati-hati predator/discontinued |
| **WoS SCIE** | Science Citation Index Expanded | Standar tertinggi, impact factor resmi JCR |
| **WoS ESCI** | Emerging Sources | Menuju SCIE, kualitas baik |

## 2. Strata Nasional (SINTA Kemenristek/Kemendikbud)

| Akreditasi | Padanan Internasional | Standar |
|---|---|---|
| **SINTA 1** | Terindeks Scopus/WoS | Standar internasional, dwibahasa atau full English |
| **SINTA 2** | Akreditasi nasional tinggi | Peer review ketat, banyak sitasi Scopus, bahasa Indonesia baku / Inggris |
| **SINTA 3** | Akreditasi menengah | Standar nasional baik |
| **SINTA 4-6** | Akreditasi dasar / regional | Tahap pembinaan |

## 3. Red Flags Jurnal Predator
- Menjanjikan "Accepted in 3-7 days" (peer review normal 1-6 bulan).
- Meminta APC (Article Processing Charge) tinggi sebelum ada peer review.
- Alamat kontak email gratisan (gmail/yahoo) bukan domain institusi.
- Dewan editor tidak terlacak di Google Scholar / Scopus.
- Terdaftar di Beall's List atau daftar discontinued Scopus terbaru.
