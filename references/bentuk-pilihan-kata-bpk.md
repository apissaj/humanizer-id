# Ekstrak Kaidah: Bentuk dan Pilihan Kata — Seri Penyuluhan Badan Bahasa 2015

- **Sumber Karya:** *Seri Penyuluhan: Bentuk dan Pilihan Kata* (Badan Pengembangan dan Pembinaan Bahasa, Kemendikbud, 2015).
- **Bab Relevan:**
  - Bab II: Subbab 2.2.1 Pembentukan Kata dengan Awalan (hlm. 9-23), Subbab 2.2.3 Pembentukan Kata dengan Sisipan (hlm. 32)
  - Bab III: Subbab 3.2.4 Pilihan Kata yang Tidak Tepat (hlm. 85-99)

---

## 1. Kaidah Preskriptif Pembentukan Kata dan Pilihan Kata

1. **Awalan ke- Adversatif Salah Kaprah (hlm. 28-29):**
   Bentukan kata dengan awalan ke- sebagai padanan verba adversatif adalah interferensi bahasa daerah. Bentukan baku menggunakan prefiks ter-: *tertabrak, tertimpa, tertubruk, tersandung, tertinggal, tertangkap*. Bentukan tidak baku: *ketabrak, ketimpa, ketubruk, kesandung, ketinggal, ketangkap*.

2. **Peluluhan Fonem /t/, /k/, /p/, /s/ pada Konfiks meN-...-kan (hlm. 21-23):**
   Fonem awal dasar /t/, /k/, /p/, /s/ wajib luluh jika dirangkaikan dengan konfiks meng-...-kan atau peng-...-an: *terap + meng-...-kan -> menerapkan* (bukan mengetrapkan/mentrapkan/menterapkan); *terap + peng-...-an -> penerapan* (bukan pengetrapan/pentrapan/penterapan). Serupa: *terjemah -> menerjemahkan* (bukan menterjemahkan); *taat -> menaati* (bukan mentaati); *kait -> mengaitkan* (bukan mengkaitkan).

3. **Pronomina Kita sebagai Pengganti Saya (hlm. 96):**
   Kata kita merupakan pronomina orang pertama jamak inklusif. Penggantian pronomina tunggal saya dengan kita dalam ragam resmi tidak dapat dibenarkan karena membedakan konsep kejamakan.

4. **Pronomina Kami pada Penulis Tunggal Karya Ilmiah (hlm. 97-99):**
   Dalam karya tulis atau surat, kami hanya sah jika penulisnya mewakili lembaga/kelompok. Penggunaan kami untuk penulis tunggal karya ilmiah tidak tepat dari segi bahasa. Alternatif: gunakan saya, penulis, atau bentuk pasif (mis. *Dalam penelitian ini akan dideskripsikan...*).

## 2. Draf Kaidah Baru untuk Dataset

### Kaidah 1: BPK-011 (Awalan ke- Adversatif Salah Kaprah)
- **ID:** BPK-011
- **Pola:** ketabrak / ketimpa / ketubruk / kesandung / ketinggal / ketangkap
- **Saran Pengganti:** tertabrak / tertimpa / tertubruk / tersandung / tertinggal / tertangkap
- **Penjelasan:** Merujuk Seri Penyuluhan Bentuk dan Pilihan Kata (hlm. 28-29), awalan ke- untuk verba adversatif merupakan bentukan tidak baku yang bersumber dari struktur bahasa daerah; bentukan baku menggunakan prefiks ter-.
- **Contoh Salah:** Ketika menyeberang rel, ia nyaris ketabrak kereta api.
- **Contoh Benar:** Ketika menyeberang rel, ia nyaris tertabrak kereta api.

### Kaidah 2: BPK-012 (Peluluhan Fonem Gagal pada Konfiks meN-...-kan)
- **ID:** BPK-012
- **Pola:** mengetrapkan / mentrapkan / menterapkan / pengetrapan / pentrapan / penterapan / menterjemahkan / mentaati / mengkaitkan
- **Saran Pengganti:** menerapkan / penerapan / menerjemahkan / menaati / mengaitkan
- **Penjelasan:** Merujuk Seri Penyuluhan Bentuk dan Pilihan Kata (hlm. 21-23), fonem /t/, /k/, /p/, /s/ pada awal kata dasar wajib luluh saat dirangkaikan dengan konfiks meng-...-kan dan peng-...-an.
- **Contoh Salah:** Peneliti harus menterjemahkan hasil kuesioner ke dalam bahasa Indonesia baku.
- **Contoh Benar:** Peneliti harus menerjemahkan hasil kuesioner ke dalam bahasa Indonesia baku.

### Kaidah 3: BPK-013 (Pronomina Kita Sebagai Pengganti Saya)
- **ID:** BPK-013
- **Pola:** [telaah] pemakaian kita untuk merujuk penulis tunggal dalam ragam resmi
- **Saran Pengganti:** saya / penulis / bentuk pasif
- **Penjelasan:** Merujuk Seri Penyuluhan Bentuk dan Pilihan Kata (hlm. 96), kita (jamak inklusif) tidak boleh menggantikan saya (tunggal) dalam ragam resmi karena menimbulkan kerancuan kejamakan.
- **Contoh Salah:** Kemarin waktu kita pulang sekolah, dia sudah ada di sini.
- **Contoh Benar:** Kemarin sewaktu saya pulang sekolah, dia sudah berada di sini.

### Kaidah 4: BPK-014 (Pronomina Kami untuk Penulis Tunggal Karya Ilmiah)
- **ID:** BPK-014
- **Pola:** [telaah] pemakaian kami pada penulis tunggal karya ilmiah
- **Saran Pengganti:** saya / penulis / bentuk pasif
- **Penjelasan:** Merujuk Seri Penyuluhan Bentuk dan Pilihan Kata (hlm. 97-99), kami hanya sah jika mewakili kelompok atau lembaga; untuk penulis tunggal karya ilmiah gunakan saya, penulis, atau bentuk pasif.
- **Contoh Salah:** Dalam penelitian ini kami bermaksud mendeskripsikan hubungan antara pendidikan dan produktivitas kerja.
- **Contoh Benar:** Dalam penelitian ini penulis bermaksud mendeskripsikan hubungan antara pendidikan dan produktivitas kerja.
