- **`E9L-026` (serapan/digraf/apostrof keliru):**
  - *Tercetak -> Seharusnya*: `Romadhon` -> `Ramadan` (hlm. 39); `muqaddimah` -> `mukadimah` (hlm. 39); `Teknologie` -> `Teknologi` (hlm. 39); `azasi` -> `asasi` (hlm. 39); `Centraal` -> `sentral` (hlm. 39); `akhlaq` -> `akhlak` (hlm. 40); `ma'siat` -> `maksiat`, `Sa'at` -> `Saat` (hlm. 41); `Alkuran` -> `Al-Qur'an`, `ke-Tuhan-an` -> `ketuhanan` (hlm. 42); `psikhologi` -> `psikologi`, `effektiv` -> `efektif`, `kwota` -> `kuota`, `extradiksi` -> `ekstradisi` (hlm. 44).

  - `K.B.` -> `KB`, `U.U.D.` -> `UUD` (hlm. 41: *"Membicarakan soal K.B."* / *"semangat U.U.D."*), `D.P.R.` -> `DPR` (hlm. 43: *"Ia seorang anggota D.P.R."*), serta `S.M.A.` -> `SMA` dan `S.M.P.` -> `SMP`.

## 3. Sintaksis Kalimat Efektif (`seri_penyuluhan_kalimat_badanbahasa_v2.pdf`, `[hlm. 25–32, 77–80]`)

- **`SPK-017` (`[hlm. 25–26]`):** Verba transitif tidak boleh dipisahkan dari objek langsungnya oleh preposisi (`*Kami mengharap atas kehadiran...`, `*Pemerintah akan membangun daripada ekonomi` -> `mengharap kehadiran...`, `membangun ekonomi`).
- **`SPK-018` (`[hlm. 30]`):** Verba intransitif/kopulatif tidak dapat dipasifkan secara takgramatikal (`*Tanggung jawab saya dijadi masalah ini`, `*Saran belaka dirupakan usulan itu` -> `Masalah ini menjadi tanggung jawab saya`, `Usulan itu merupakan saran belaka`).
- **`SPK-019` (`[hlm. 28]`):** Kalke siaran *This is Sari reporting from Makassar* -> `*Ini Sari melaporkan dari Makassar` diperbaiki menjadi **`Demikian(lah) laporan Sari dari Makassar`**.
- **`SPK-020` (`[hlm. 30, 79–80]`):** `[telaah]` Pelengkap pada verba dwitransitif (*mengajari, membelikan, menghadiahi*) tidak boleh dijadikan subjek pasif (`*Cara beternak belut diajari orang itu kepada adik saya`), dan klausa majemuk koordinatif wajib menjaga kesejajaran pola (`S-P dan P-S`) maupun kategori frasa (`dalam rangka FN, FV, serta FV`).
- **`SPK-021` (`[hlm. 25, 32]`):** `[telaah]` Kalimat takberobjek pada verba transitif wajib (`*Jaksa menghadirkan`, `*Ketua MPR menghadiri`, `*Para saksi mengatakan`) atau tanpa pelengkap wajib (`*Tugu Monas berada`, `*Raja Buton pertama berasal`).
