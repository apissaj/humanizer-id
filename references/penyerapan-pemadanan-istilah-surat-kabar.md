# Ekstrak Kaidah: Penyerapan dan Pemadanan Istilah Asing pada Surat Kabar (Baharman, UNM)

- **Sumber Karya:** *Penguatan Bahasa Indonesia melalui Penyerapan dan Pemadanan Istilah Asing pada Surat Kabar*, Baharman, Universitas Negeri Makassar (Makalah Kongres Bahasa Indonesia X, Badan Bahasa Kemdikbud), berbasis Surat Kabar Tempo edisi Senin 23 Oktober 2017 No. 5667 Tahun XVII.
- **File:** `books/penguatan_penyerapan_pemadanan_istilah.pdf` (22 hlm; repositori kemendikdasmen 11100).
- **Fokus Bedah:** Kaidah penyerapan (adopsi, adaptasi, penerjemahan, kreasi), pemadanan istilah, rambu-rambu PUPI, aturan penulisan istilah asing dalam ragam jurnalistik/media.

## 1. Empat Kaidah Penyerapan Istilah Asing (hlm. 10-11)

1. **Mengadopsi (adopsi):** bentuk dan makna kata asing diambil menyeluruh tanpa perubahan ejaan. Contoh sah: `merger`, `laptop`, `mall`, `moratorium`, `referendum`, `Facebook`, `final`.
2. **Mengadaptasi (adaptasi):** makna diambil, ejaan/penulisan disesuaikan kaidah fonotaktik Indonesia. Contoh: `acculturation` → `akulturasi`; `analysis` → `analisis`; `budget` → `bujet`; `asse(t)` → `aset`; `project` → `proyek`; `illegal` → `ilegal`; `extra` → `ekstra`; `inflation` → `inflasi`; `attention` → `atensi`; `auditing` → `auditor`; `exposure` → `ekspose`; `touring` → `tur`.
3. **Menerjemahkan (penerjemahan):** konsep dipadankan dengan kata/ungkapan Indonesia. Contoh: `gadget` → `gawai`; `hub` → `pusat`; `check-in` → `mendaftar`; `effort` → `upaya`; `existing` → `ada`; `reshuffle` → `perombakan`; `artificial intelligence` → `kecerdasan buatan`; `supermarket` → `pasar swalayan`; `merger` → `gabungan usaha`; `bonded zone` → `kawasan berikat`; `skyscraper` → `pencakar langit`.
4. **Mengkreasi (kreasi):** konsep dasar direka baru dalam Indonesia, bentuk fisik bebas. Contoh: `spare parts` → `suku cadang`; `situs web` → `laman`; `online` → `daring`; `game` → `gim`; `selfie` → `swafoto`; `zebra cross` → `jalur pejalan kaki`; `mass rapid transit` → `moda raya terpadu`; `light rail transit` → `kereta ringan`; `factoring` → `anjak piutang`; `catering` → `jasa boga`; `invention` → `rekacipta`.

## 2. Rambu-Rambu Penyerapan (PUPI, Kepmen Diknas 146/2004; hlm. 16-17)

Istilah asing layak diserap (bukan diterjemahkan) bilamana:
1. Meningkatkan ketersalinan timbal balik (intertranslatability) dengan bahasa sumber.
2. Mempermudah pemahaman teks asing karena bentuknya sudah dikenal.
3. Lebih ringkas daripada terjemahan Indonesianya.
4. Mempermudah kesepakatan antarpakar bila padanan terjemahannya terlalu banyak sinonim.
5. Lebih cocok dan tepat karena tidak mengandung konotasi buruk (harus konotasinya baik, sedap didengar/eufonik, dan seturut kaidah bahasa Indonesia).

## 3. Aturan Pemakaian Istilah Asing dalam Naskah (hlm. 9, 17)

1. **Kursif:** istilah asing yang belum diserap wajib ditulis miring/kursif (bukan tanda petik) dalam ragam jurnalistik.
2. **Urutan padanan:** bila ada padanan Indonesia, tulis bentuk Indonesia lebih dulu, diikuti bentuk asing dalam kurung — bukan sebaliknya. Pola salah: *online (dalam jaringan)*; pola benar: *dalam jaringan (online)*.
3. Istilah asing sah dipakai bila: (a) memperhalus makna (*cleaning service*), (b) terjemahan mengurangi makna (*Windows*, *Server*, *Port*), (c) mengungkap budaya asing yang dikenal (*opera*, *ballet*).
4. Penggunaan istilah asing sepatutnya diikuti terjemahan/padanan Indonesia pada pemakaian pertama.

## 4. Parameter Keberterimaan Serapan (hlm. 10)

1. Konotasi serapan cocok dengan konsep sumber.
2. Bentuk serapan lebih singkat daripada terjemahan.
3. Serapan memudahkan kesepahaman bila padanan Indonesia terlalu sinonim.

## 5. Data Pemadanan dari Tempo 2017 (Tabel 1-2, hlm. 12-13)

- Dari 59 istilah asing dalam korpus: hanya 18 (30,5%) sudah diserap baku; 41 (69,5%) masih asing; hanya 5 berpadanan resmi: `situs web` → `laman`, `online` → `daring`, `reshuffle` → `perombakan`, `MRT` → `moda raya terpadu`, `selfie` → `swafoto`.
- Padanan baku terverifikasi lain: `commuter line` → `kereta komuter`, `busway` → `jalur bus`, `year to date` → `sejauh tahun ini`, `month to month` → `bulan ke bulan`, `indoor` → `dalam ruangan`, `powerful` → `kuat penuh` (redundan, cukup `kuat`).
