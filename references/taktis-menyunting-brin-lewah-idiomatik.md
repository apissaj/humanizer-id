# Taktis Menyunting (BRIN, 2019) - bentuk lewah dan ungkapan idiomatik

Sumber: Badan Riset dan Inovasi Nasional, *Taktis Menyunting: Panduan ...*,
2019. Bab V "Praktik Menyunting Bahasa", butir 2 dan 4 (hlm. 102-106).
Buku menyatakan "Buku ini tidak diperjualbelikan"; kutipan dipakai sebagai
rujukan kaidah, bukan salinan isi buku.

## 2. Menyunting bentuk lewah (mubazir), Tabel 5.6, hlm. 102-103

> Bentuk mubazir atau tidak efektif sering kali muncul di dalam karya tulis.
> Bentuk ini terkadang dipengaruhi oleh bahasa lisan yang kita gunakan.

| Bentuk lewah (buku) | Bentuk efektif (buku) |
|---|---|
| luar biasa sempurna | sempurna |
| sangat sempurna sekali | sempurna |
| sangat jauh sekali | sangat jauh atau jauh sekali |
| banyak buku-buku | banyak buku |
| beberapa pendapat-pendapat | beberapa pendapat |
| demi untuk negara | demi negara atau untuk negara |
| bertujuan untuk memulihkan | bertujuan memulihkan |
| membicarakan tentang pandemi | membicarakan pandemi |
| melakukan penangkapan | menangkap |
| melakukan pembinaan | membina |
| melakukan perubahan | mengubah |
| menyatakan pendapat | berpendapat |
| adalah merupakan | adalah atau merupakan |
| disebabkan karena | disebabkan oleh atau karena |
| kurang lebih sekitar | kurang lebih atau sekitar |
| pada zaman dahulu kala | pada zaman dahulu atau dahulu kala |
| semata-mata hanya | semata-mata atau hanya |
| menggabungkan menjadi satu | menggabungkan atau menyatukan |
| saling salip-menyalip | saling menyalip atau salip-menyalip |
| menanyakan pertanyaan | mempertanyakan |
| berencana akan | berencana |
| agar supaya | agar atau supaya |
| seperti misalnya | seperti atau misalnya |
| misteri rahasia | misteri, rahasia |
| hanya ... saja | hanya ... atau ... saja |
| seperti ... dan sebagainya | seperti ... atau ... dan sebagainya |
| tujuan daripada proposal ini | tujuan proposal ini |
| Maka daripada itu | Maka dari itu |
| Namun demikian | Namun |
| maju ke depan | maju |
| mundur ke belakang | mundur |

Dipasang sebagai kaidah **TMS-005** (14 pasang yang belum tercakup entri lain):
sangat sempurna sekali, sangat jauh sekali, banyak buku-buku,
beberapa pendapat-pendapat, melakukan penangkapan, melakukan pembinaan,
melakukan perubahan, menyatakan pendapat, menggabungkan menjadi satu,
saling salip-menyalip, menanyakan pertanyaan, berencana akan,
maka daripada itu, maju ke depan.

Tidak diaktifkan: `luar biasa sempurna -> sempurna` (frasa penilaian lazim),
`mundur ke belakang -> mundur` (jarang muncul, dan pola `kata + ke + arah`
berisiko false-positive pada arah sungguhan).

## 4. Menyunting ungkapan idiomatik, Tabel 5.8, hlm. 105-106

> Kekhasannya karena penggunaan kata depan dan kata hubung yang tidak boleh
> dihilangkan atau diganti.

| Bentuk tepat | Bentuk tidak tepat |
|---|---|
| terdiri atas / terdiri dari | terdiri |
| terbuat dari | terbuat |
| terhindar dari | terhindar |
| terlepas dari | terlepas |
| berasal dari | berasal |
| terjadi karena | terjadi atas |
| disebabkan oleh | disebabkan karena |
| bergantung pada | bergantung kepada, tergantung dari |
| berdasar atas, berdasarkan | berdasarkan atas |
| berharap akan | berharap |
| dibanding dengan | dibandingkan dengan |
| sesuai dengan | sesuai |
| antara ... dan ... | antara ... dengan ... |
| baik ... maupun ... | baik ... ataupun ... |
| tidak ..., tetapi ... | tidak ..., melainkan ... |
| bukan ..., melainkan ... | bukan ..., tetapi ... |
| sehubungan dengan | sehubungan |
| terkait dengan | terkait |

Dipasang sebagai kaidah **TMS-006** (3 pasang yang belum tercakup entri lain):
berdasarkan atas, bergantung kepada, terjadi atas. Bentuk `tergantung dari`
sudah masuk `TBI-001`; `terdiri dari`, `disebabkan karena`, `sesuai dengan`,
`sehubungan`, `terkait`, dan `dibandingkan dengan` sudah ada di data.

Tidak diaktifkan: `berharap` telanjang (dalam banyak kalimat sah tanpa
`akan`), `dibandingkan dengan` (masih dipakai luas dan diterima), serta
pasangan korelatif `tidak ..., melainkan ...` / `bukan ..., tetapi ...`
karena sudah tercakup `SPK-010`, `RET-007`, dan `JRN-003`.
